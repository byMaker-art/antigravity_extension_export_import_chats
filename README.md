# Antigravity IDE & 2.0 Chat Sync (Экспорт и импорт диалогов)

Инструмент для экспорта, импорта и синхронизации истории чатов **Antigravity IDE** между несколькими компьютерами (например, **iMac ↔ MacBook**).

---

## 🎯 В чем проблема и как она решается?

По умолчанию Antigravity IDE (и Antigravity 2.0) хранит все диалоги не внутри папки проекта, а локально в домашней директории пользователя:
- `~/.gemini/antigravity/conversations/<uuid>.db` — полная история шагов, сообщений и вызовов инструментов (SQLite WAL).
- `~/.gemini/antigravity/brain/<uuid>/` — артефакты, логи, черновики (`scratch`), медиафайлы.
- `~/.gemini/antigravity/conversation_summaries.db` — общий реестр диалогов с привязкой к URL проекта (`workspace_uris`).

Когда вы открываете проект на другом компьютере, папка проекта синхронизирована (через **iCloud Drive** или **Git**), но локальная база `~/.gemini/antigravity` на втором Mac пуста или содержит только старые локальные чаты.

### 💡 Решение
Скрипт `antigravity_chat_sync.py`:
1. Находит все диалоги, относящиеся к **текущему проекту**.
2. Безопасно выгружает их (сбрасывая WAL-кэш SQLite без повреждения БД) в папку `.antigravity_chats/` внутри проекта.
3. Поскольку папка проекта находится в **iCloud Drive** (или Git-репозитории), папка `.antigravity_chats/` **автоматически переносится на ваш второй Mac**.
4. На втором Mac достаточно запустить команду импорта или открыть проект — и диалоги автоматически регистрируются в локальном Antigravity с **корректной адаптацией путей** (даже если имена пользователей или пути на iMac и MacBook немного различаются!).

## 🚀 Быстрый старт

Скрипт не требует сторонних библиотек — работает на стандартном **Python 3**, предустановленном в macOS.

### 1. Посмотреть диалоги текущего проекта
```bash
python3 antigravity_chat_sync.py list
```

### 2. Экспортировать диалоги проекта
```bash
python3 antigravity_chat_sync.py export
```
Внутри проекта появится папка `.antigravity_chats/`:
- `conversations/*.db` — базы диалогов;
- `brain/*` — артефакты и логи;
- `readable_transcripts/*.md` — **читаемый Markdown** диалогов (можно читать в любом текстовом редакторе или Obsidian!);
- `metadata.json` — метаданные для импорта.

### 3. Импортировать на втором Mac
После того как iCloud синхронизирует проект на MacBook:
```bash
python3 antigravity_chat_sync.py import
```
Все диалоги появятся в Antigravity IDE!

### 4. Умная синхронизация (Sync)
```bash
python3 antigravity_chat_sync.py sync
```
Автоматически проверяет время последних изменений:
- Если локальные диалоги новее — выполнит `export`.
- Если в проекте лежат более свежие данные со второго Mac — выполнит `import`.

## ⚡ Интеграция с Antigravity IDE (VS Code Tasks)

Так как Antigravity IDE создана на ядре **VS Code**, вам даже не обязательно открывать терминал! В проекте уже настроен файл `.vscode/tasks.json`.

1. Нажмите в Antigravity IDE: **`Cmd + Shift + P`**
2. Введите: **`Tasks: Run Task`**
3. Выберите нужную команду:
   - **Antigravity: Smart Sync Chats** (умная синхронизация)
   - **Antigravity: Export Project Chats**
   - **Antigravity: Import Project Chats**
   - **Antigravity: List Project Chats**

> [!TIP]
> В `.vscode/tasks.json` задача `Smart Sync Chats` настроена с флагом `"runOptions": { "runOn": "folderOpen" }`.
> При открытии папки проекта Antigravity IDE может автоматически синхронизировать чаты!

## ❓ Ответы на важные вопросы

### 1. «Можно ли сделать проще — например, сделать симлинк `~/.gemini/antigravity` в iCloud?»
**Крайне не рекомендуется!** 
- Базы данных Antigravity (`conversations/*.db`, `conversation_summaries.db`) работают в режиме **SQLite WAL** (`-wal` и `-shm`).
- Облачные сервисы (iCloud, Dropbox) не умеют синхронизировать низкоуровневые блокировки файлов (`flock`). Когда SQLite пишет во временный WAL-файл, iCloud блокирует или дублирует его с конфликтом имён.
- Если Antigravity открыт одновременно на двух компьютерах или если соединение оборвется во время записи — базы данных **повредятся** (`database disk image is malformed`).
- Наш скрипт использует встроенный механизм `sqlite3.backup()`, который производит **атомарный сброс WAL в чистый файл**, полностью исключая повреждение данных.

### 2. «Поможет ли написание собственного расширения (VS Code Extension)?»
**Да, поможет, но Tasks проще и универсальнее:**
- Antigravity IDE действительно на 100% совместима с расширениями VS Code (`.vsix`).
- **Что дает расширение:** Кнопку прямо в StatusBar (внизу экрана) со стрелочками «Синхронизировать чаты» и перехват событий открытия/закрытия окна без запроса разрешений.
- **Минус расширения:** Его нужно компилировать (`vsce package`) и устанавливать отдельно на iMac и MacBook, а при обновлениях IDE следить за совместимостью.
- **VS Code Tasks (`.vscode/tasks.json`):** Решают ту же самую задачу прямо из коробки, не требуют компиляции и хранятся прямо в проекте.
